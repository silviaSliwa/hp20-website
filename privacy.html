Översikt

HP2.0 är en iOS-app för förberedelse inför Högskoleprovet. Appen kräver inget användarkonto och har ingen inloggning. Den här policyn beskriver hur appen och den här webbplatsen hanterar information.

Studiedata i appen

Dina svar, resultat, studieframsteg, misstag, sviter, inställningar och valda studiemål sparas lokalt på din enhet. Uppgifterna används för att visa din utveckling och anpassa träningen. HP2.0-utvecklaren tar inte emot eller lagrar denna studiedata på en egen server.

Analys, spårning och diagnostik

HP2.0 använder inte externa analysverktyg, annonsnätverk, spårning eller kraschrapportering. Appen säljer inte personuppgifter. Den obligatoriska integritetsmanifestdeklarationen för UserDefaults beskriver en lokal systemfunktion som används för att spara appdata; den innebär inte i sig att uppgifter samlas in eller skickas från enheten.

Prenumerationer och Apple

Månads- och årsprenumerationer köps och hanteras genom Apples App Store med StoreKit. Apple behandlar betalning, Apple-konto och transaktionsdata enligt Apples egna villkor och integritetspolicy. HP2.0 får tillgång till produkt- och prenumerationsstatus som behövs för att låsa upp Premium, men hanterar inte dina kort- eller bankuppgifter.

Webbplats och support

Webbplatsen är statisk och använder inga egna formulär, cookies eller analysverktyg. Den levereras via GitHub Pages, vilket innebär att GitHub kan behandla tekniska uppgifter om webbförfrågningar enligt sin egen integritetspolicy. Om du kontaktar supporten via e-post behandlas din e-postadress och den information du själv väljer att skicka för att kunna besvara ärendet.

Lagring och dina val

Lokala appdata finns kvar på enheten tills appen eller dess data tas bort. Prenumerationer kan hanteras via ditt Apple-konto. E-post till supporten sparas bara så länge den behövs för att hantera ärendet och eventuella rättsliga skyldigheter.

Ändringar av policyn

Policyn kan uppdateras om appens funktioner eller datahantering ändras. Den senaste versionen publiceras på den här sidan med ett nytt datum.

Kontakt

Vid frågor om integritet kan du kontakta HP2.0-teamet på hp20appen@outlook.com.
